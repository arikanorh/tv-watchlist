# tv-watchlist

Personal TradingView-style watchlist: one static `index.html` (vanilla JS, no build, no backend) with live quotes, a TradingView chart widget and multiple watchlists. Goal: reach several lists quickly, see how each is doing (sentiment %), open a symbol's chart when needed. Live at https://arikanorh.github.io/tv-watchlist/ and https://tv-watchlist.pages.dev (both serve `main`). Owner: arikanorh (personal GitHub, not the work GHE).

Read `DATA-SOURCES.md` for the exact protocols (websocket framing, scanner payloads, widget postMessage API, BOATS overnight, field catalog).

## Files

| Path | Role |
|---|---|
| `index.html` | The whole app: CSS, markup, JS (~1100 lines). Only deliverable. |
| `manifest.webmanifest`, `icons/` | PWA (iOS home screen, standalone) and favicons (`icon-32`, `icon-192`). `background_color` = nav color. |
| `relay/worker.js` | Cloudflare Worker: relays the TradingView quote websocket for non-localhost origins, proxies `/search`, keeps synced lists in a `SyncRoom` Durable Object per code (`/state/<code>` REST, `/sync/<code>` websocket push; legacy KV `tv-watchlist-sync` is read once). |
| `relay/wrangler.toml`, `relay/README.md` | Worker config + deploy notes. |
| `.github/workflows/deploy-relay.yml` | Deploys the worker on push to `main` when `relay/**` changes (secret `CLOUDFLARE_API_TOKEN`); creates and binds the sync KV namespace. |
| `DATA-SOURCES.md` | Reverse-engineered TradingView endpoints and their quirks. |
| `reference/` | Git-ignored. Field catalog dump and the user's real TradingView watchlist snapshot. |

## Runtime architecture (index.html)

**State** — `state` in `localStorage` key `tvwl.state.v2`: `{ activeListId, interval, symbol, view, sort, chartHidden, listHidden, ownChart, chartOpts, flags, migrated[], lists:[{id, name, summary, groups:[{name, collapsed, symbols[]}]}] }`. `summary` is `true` (average of the list's equities), a symbol string (TR → `BIST:XU100`) or `false`. `seed()` builds the default lists; `load()` runs `SYMBOL_FIXES` / `REMOVED`, one-time migrations recorded in `migrated`, drops keys of the previous design (pinned, details, history), and `ensureEarnings()` keeps the **Earnings** list (`auto: 'earnings'`, a list already named Earnings is adopted) last with two groups: "Upcoming" (`auto`, rebuilt by `updateEarnings()` after each quote batch from every other list's symbols whose `earnings_release_next_date` is 0–7 days away, sorted by day; rows can't be moved/removed/dragged; never synced) and "Manual" (the user's own; the Add row and "Add to list" put symbols there, which then leave Upcoming). The list can't be deleted or reordered; new lists go before it. Bumping `KEY` would reset everyone's lists.

**Layout** — mobile first. Phone: one pane at a time (`body[data-view]` = `list` / `chart`) behind a two-tab nav (Liste / Grafik). What you read is at the top, what you tap at the bottom:
- Header `.top` (session-tinted: pre amber, open green, post blue, overnight purple): list name + sentiment % on the list pane, symbol + last + chg% on the chart pane (tap → search); then the pins. The session label / last tick time + status dot block (`#hr`, tap → reconnect) shows only on desktop with the chart hidden.
- List pane: table (Symbol / Last / Chg% / Ext; Ext hidden during the regular session via `body.regular`), collapsible groups, then the dock: one chip per list with its sentiment % (tap → switch; the row scrolls sideways, the mouse wheel scrolls it too), `⋯` (list manager) and `⚙` (settings: sync box, version, reconnect); every list ends with an add row (`.addrow`: "+ Add Symbol" → search in add mode, "+ Add Section" → `addSection`, a new group at the end; not on the Earnings list; both half width); the Chg% and Ext column headers toggle the sort (`state.sort` = `chg` / `ext` / null).
- Chart pane: TradingView widget and its toolbar `.ctools` = interval segmented control (`#seg`) + chart bar (`Search`, `ⓘ` details). Phones: under the chart, intervals above the search row. Desktop: the search box (symbol, last, chg%: `#cbSym/#cbPx/#cbChg`) and the full interval segmented control float over the chart's top-left corner (`.cover`, moved there by `placeTools`); the toolbar row above the chart (50px, session-tinted) holds the pinned quick symbols (`PINS`: US100, BTC, US10Y, VIX — two lines, left-aligned: name, then last (no decimals from 1,000) + chg%; click → chart; always subscribed via `allSymbols`; on phones `placeTools` moves `#pins` into the header right of the list name — the same two-line cells, smaller, scrollable if tight; the session/clock block `#hr` is hidden on phones, the tint tells the session and reconnect is in Settings); the `ⓘ` details button is phone-only. The header's `#hr` block (session label, tick time + version, chart-hide button) is not shown on desktop while the chart is visible (the toolbar's session tint is the cue; hide-watchlist (`state.listHidden`, `body.list-hidden`: the list column collapses to 0) and hide-chart buttons sit at the toolbar's far right; never both hidden); it appears in the full-width header when the chart is hidden (`placeTools` keeps it in `.top`).
- Details (`detailsHtml`): today range, open, prev close, volume vs average; 52-week range, 1W / 52W / from-ATH; valuation (market cap, P/E, EPS, P/S, P/B, dividend yield, beta); company (sector, industry, country, revenue, net margin, next earnings, analyst target). Phones: a bottom sheet (`toggleDetails`), also from the row menu. Desktop: a 300px column between list and chart (`state.detailsOpen`). Re-rendered on every quote batch.
- ≥768px: `body` becomes a grid: the list pane (380px) fills the full height on the left, topped by `.lblock`: the sentiment chart `#sent` with the list head (`.lhead`: list name + sentiment %) floating over its top-left corner, above the table; the header `.top` is hidden (its contents live in the chart toolbar) unless the chart is hidden, when it spans the full width above the list; details (optional) | chart fill the rest; `.main` is `display: contents`; the dock's list chips render as underlined tabs (name + sentiment %) on desktop; nav hidden; header button hides the chart (`state.chartHidden`).
- Sentiment chart (desktop only, `renderSentiment`): a plain line of the active list's sentiment % over time (green above zero, red below, dashed zero line when in range) from `hist` (`tvwl.hist.v1`; `sampleHistory` every 15 s while open, 2 h at full rate, thinned to 1/min, 24 h kept), y axis scaled to the range's min/max (labels placed on the side away from the extreme). Clicking the chart cycles the range shown top-right: Today/Overnight (current session from `sessionOpenTs`: 04:00 or 20:00 ET) → 1h → 4h → 24h; opens on the session every load; hover shows time and value.

**Interactions** — one delegated `click` handler on `document` dispatches on `data-act`. Rows: tap → `selectSymbol()` (chart; phones switch to the chart pane; the already-selected symbol is a no-op apart from the view switch). Press and hold 420 ms (a mouse drags right away after 8px) → the row lifts: release in place → actions sheet (`openRowMenu`: details, flag, add to another list (`openCopySheet`; the symbol stays here too), add section above (`addSection({gi, i})`: the row and those below it move into the new group), move up / move down within the group (hidden in sorted view), remove from the list — asks first: the option arms on the first tap ("Remove X? Tap again"), the inline ✕ arms for 3 s — then an undo toast; removals stack (`undoable`/`undoStack`): "CRWV removed (+2 more) · Undo 3", each Undo takes back the latest, cleared 8 s after the last removal); drag → reorder within/between groups (pointer events on `#rows`, a non-passive `touchmove` stops scrolling once lifted). Desktop: hovering a row shows inline icon tools `.rt` (details, add to list, remove; `ICON`) plus the flag strip `.fl` (the 8px left border itself, no icon; each click cycles the color, `cycleFlag`), right-click opens the same sheet, and the keyboard: ↑/↓ walk the visible rows and update the chart, ←/→ switch watchlists (ignored while a sheet or input has focus); any letter opens search with it typed; digits 1–8 open the interval picker (`openIntervalPicker`) and, while it is open, pick the interval. Sorted view (`state.sort` = `chg` or `ext`): non-equities stay on top as "Index", the rest is one "By change" / "By ext" group by that column; drag and the inline up/down are off. Sheets (`openSheet`/`closeSheet`) are bottom sheets on phones and centered dialogs on desktop: row actions, add-to-list, interval, search (`openSearch(addMode)`, input at the bottom on phones; ↑/↓ move the highlight, Enter picks it, even while results load; from the list's "Add symbol" row Enter/tap adds to the active list and stays, from the chart it only opens the chart; each result's `+` adds in both), list manager (`openListManager`: rename, ↑/↓, Σ sentiment on/off, delete with a second tap, new list), settings (`openSettings`: sync box, own-chart toggle, version, reconnect).

**Chart** — `CHART_ALIAS` charts an equivalent feed for symbols the embed won't chart (`TVC:US10Y` → `PYTH:US10Y`, `TVC:VIX` → `CAPITALCOM:VIX`; aliased symbols are exempt from `noChart`; `TVC:TNX`, `FRED:*`, CME/CBOT futures show "only available on TradingView"). TradingView Advanced Chart free widget (`mountChart()`), toolbars/legend/volume off, `sessionId: '24h'`. Symbol and interval changes go through the undocumented iframe postMessage API (`send('set-symbol'|'set-interval')`), so the chart never reloads; messages queue until the iframe's first message (`chart.ready`). A widget mounted while its pane has no size stays blank, so `chart.hiddenAtMount` triggers a remount when the pane shows (`setView`, resize). The free widget cannot chart BIST or plain indices (`noChart()`): those symbols open **our own chart** instead (`showOwnChart` / `#ownChart` over the widget in `.charea`): history and live bars from TradingView's chart websocket (`chart_create_session` / `resolve_symbol` with the chart option "Session" (`regular` / `extended` / `24h` — the latter adds the overnight Blue Ocean bars for US stocks, others fall back to `extended`; default `24h`) / `create_series`, 300 bars, unauthorized token — BIST is delayed; direct on localhost, via the relay elsewhere; one session per request, replies matched by session id), drawn with Lightweight Charts 4.2 loaded from unpkg on first use (its logo is off; our icon sits bottom-left and switches to the TradingView widget, a "TV" box in the same spot over the widget switches back — both flip `state.ownChart`; the attribution link is in Settings). Intraday bars are shifted to local time; our own last-price label (`ownCountdown`, `.plabel`: price, day change %, bar-close countdown for minute intervals, in one box; the library's label is off) sits on the price axis; the ⚙ in the bottom-right corner where the axes meet (`openChartOpts`: on desktop a context-style checklist menu `.cmenu` beside the gear that stays open while toggling, with "Session" as a flyout submenu to the left (hover or click), closes on outside click/Esc; a sheet on phones; `CHART_OPTS`/`setChartOpt`) toggles the % and countdown lines, the session shading, the volume histogram (`own.vol`, bottom fifth, candle-colored, chart option "Volume") (`ownSessions`, `.sessbg`: pre/post/overnight tints behind the bars for US symbols on minute intervals, phases from ET bar times; `state.chartOpts`, local). `setChartInterval` re-requests the series while the own chart is active. Settings has "Own chart for all symbols" (`state.ownChart`, local): `useOwn()` routes every symbol to our chart and `mountChart` skips the widget.

**Quotes** — `raw[sym]` holds merged websocket fields; `quotes[sym] = {p, c, e, ep, ss}` (last, chg%, extended chg%, extended price, session dot). Sources:
1. Websocket: direct on localhost, `RELAY_WS` elsewhere (TradingView accepts the handshake only from allow-listed origins). Subscribed set = every symbol of every list (`allSymbols()`), so all chips show live sentiment. Watchdog: 30 s without any `qsd` while the socket is open → reconnect (the session can go silent while heartbeats continue).
2. Overnight (20:00–04:00 ET): `wsSync()` also subscribes each US stock's `BOATS:<ticker>` twin; `onQuote` takes the overnight price from it and computes the change against the regular close. Dropped when the phase ends (`renderSession`).
3. If the socket never opens → `quoteSource = 'poll'`: scanner REST every 10 s, hidden mini widgets (`syncFeeders`, max 4) for symbols the scanner lacks. `?quotes=poll` forces it.
`renderQuotes()` (throttled 250 ms) patches cells in place with flash, refreshes chips and header; in sorted view it re-orders at most every 3 s and never under a finger or an open sheet. Outside regular hours Last shows the extended price and Ext the extended change with a colored dot (amber pre, blue post, purple overnight). Prices: 2 decimals ≥ 1, T/B above a billion, 4 significant digits below 1 (`fmtPrice`). Earnings within 7 days show a tag next to the ticker.

**Sync across devices** — the lists (`syncShape`: id, name, summary, auto flag, groups with name and symbols — the Earnings list's auto group is left out) live in the relay worker, one `SyncRoom` Durable Object per code (codes stored in KV before v1.8 are copied into the room on first use), under a code of 4–12 letters/digits (random ones are 4 characters without I, O, 0, 1 and checked to be unused; the user can type their own; 12-character codes from v1.3–1.5 still work) (`GET/PUT /state/<code>`). The room also tracks devices: each client sends a stable id (`tvwl.client` in localStorage) and a UA label (`SYNC_NAME`, e.g. "iPhone · app") as `?client=`/`?name=` on the websocket and PUT URLs; the worker stores `devices` (id → name, last seen; 90 days) and broadcasts `{type:'peers', live, devices}` on connect/close, shown in the sync box (`devicesHtml`: live count, device list). `state.flags` (symbol → color name; TradingView-style flags drawn as the row's 8px colored left border (`.row.flagged`; the selected row no longer has an accent border), set from the row menu / inline flag tool via `openFlagSheet`; `FLAGS` has the six colors) travels with the doc too; the worker stores every field beyond `updatedAt`/`lists` and, when a PUT from an older client lacks one, keeps the stored value, so old and new versions can share a code (clients ignore fields they don't know and only adopt `flags` when present). Per-device things stay local: active list, symbol, view, interval, collapsed groups, history. `save()` → `syncNoteChange()` stamps `state.sync.updatedAt` when the synced shape changed and pushes 0.5 s later. Live updates: `syncConnect()` holds a websocket to the code's room (`/sync/<code>?client=<id>`); the room sends its copy on connect and after every save from another device (`syncReceive`: newer → adopt, older → push ours; waits while a row is pressed). Keep-alive ping/pong every 30 s, reconnect with backoff, reconnect + `syncPull()` on resume; the 60 s poll only runs without a live socket. The worker answers 409 to an older PUT. Sync box (settings sheet `openSettings`, not the list manager): off = one code field (prefilled with the last code or a random suggestion) + Turn on (`useSyncCode`: a code in use replaces this device's lists, a free one starts with them); on = code + Copy + Turn off. To change the code: turn off, edit, turn on. When a pull brings in another device's edits, `showSyncNote` shows a 6 s note under the header with the symbols added/removed per list (`syncDiff`); using a code explicitly skips it. `#sync=CODE` in the URL opens settings with the code filled in. iOS home-screen apps have their own storage, so enter the code inside the app. `?sync_api=http://localhost:8788` points the client at a local `wrangler dev` for testing.

**PWA / iOS** — `fitStandalone()` drops the nav's home-indicator padding when iOS stops the web view short of the screen (`body.ios-gap`); `unshift()` snaps the document back after keyboard use (otherwise taps land off target); `trackKeyboard()` keeps bottom sheets above the keyboard (`--kb`).

**Tab title** — `renderHeader` sets `document.title` to the chart symbol and its chg%, plus the extended-hours chg% outside regular hours (e.g. `CRWV -15.46% · ext +0.80%`).

**Versioning** — `APP_VERSION` shows in the nav (phones) and at the right end of the chart toolbar (desktop, `#tver`; also in the header when the chart is hidden); bump it on every push to `main`. Off localhost the page re-fetches itself on load and on resume and reloads when the live version differs. On localhost/LAN it live-reloads on file change.

## Vocabulary

The owner calls a watchlist's aggregate move **sentiment**: *sentiment yüzdesi* = the list's day % (`listValue`, from `summarySymbols`: equities only, TR → XU100, Krip → USDT pairs only; outside regular hours it uses the extended move); *sentiment grafiği* = its history chart (`renderSentiment`, desktop only). The per-symbol *sentiment bar'ı* of earlier versions is not in 1.0.

## Constraints and decisions

- Single file, no framework, no backend, no build step.
- Mobile first; information at the top, interaction at the bottom.
- Nothing may depend on the user's logged-in TradingView account. Only on an explicit "listeleri güncelle" request: read `GET /api/v1/symbols_list/custom/` from a TradingView tab the user opened, snapshot to `reference/`, update `seed()`.
- The chart widget is official; the websocket, scanner, symbol search and iframe postMessage API are reverse-engineered and may break without notice. Keep the polling fallback working.
- Replies to the user in Turkish with English technical terms; terse progress updates.

## Known gaps / ideas

- Groups: created at once as "Section" / "Section 2"… (`addSection`: add row → Section, or "Add section above" from a row menu, which splits the group), re-cut by dragging the header like a divider between rows (`moveDivider`: the rows it passes change section; the first header stays put; a ghost copy follows the pointer, rows too) or reordered whole from the section sheet (`moveGroup`; the Earnings "Upcoming" group stays first), renamed and deleted (section sheet `openGroupMenu`: hold-release on phones, right-click on desktop; deleting merges its symbols into the previous section — or the next for the first — with an undo toast), collapsed, and symbols moved between them.
- `OANDA:XAUEUR`, `FX_IDC:XAUTRYG`, `INDEX:S5FI` have no scanner data (websocket covers them).
